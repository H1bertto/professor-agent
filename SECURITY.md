# Security Policy

## Supported versions

Professor Agent has no stable release yet. Security fixes land on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. Include the steps to reproduce, the impact you expect, and the commit or version you tested.

You can expect a first answer within 7 days. We will keep you updated while we work on a fix and credit you in the release notes if you want.

## Scope notes

These are the areas where a report is most useful:

- **API keys.** The app stores your AI provider keys in the operating system credential store. Any path that writes them to disk in plain text, to logs, or to the renderer process is a vulnerability.
- **Local server.** The Python core listens on `localhost` only. Any way for a web page or another machine to reach it is a vulnerability.
- **Content from the model.** Text generated by the LLM is untrusted. Any way for it to run code or open files through the desktop app is a vulnerability.
